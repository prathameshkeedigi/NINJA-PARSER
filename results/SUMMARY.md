## What each project tests

- **01_basic_exe**: One executable from 4 C files: the simplest compile + link graph.
- **02_static_lib**: A static library (.a built with ar) linked into an executable.
- **03_shared_lib**: A shared library (DLL): the link step has an extra output (import library).
- **04_lib_chain**: Library chain: app -> libmid -> libbase (transitive link dependency).
- **05_generated_header**: A generator program is built and run during the build; it writes keywordhash.h, which tokenize.c includes (like SQLite's mkkeywordhash).
- **06_generated_source**: A generator writes BOTH parse.c and parse.h in one step (two outputs, like lemon); parse.c is then compiled.
- **07_compile_definitions**: Compile definitions and options, including a string with a space and quotes (tests escaping inside build.ninja variables).
- **08_include_dirs**: Sources in src/, headers in two separate include folders (-I flags).
- **09_subdirectories**: add_subdirectory: the project is split into lib/ and app/, each with its own CMakeLists.txt.
- **10_object_library**: An OBJECT library: the same .obj files are linked into two different executables.
- **11_custom_target_postbuild**: A custom target that always runs, plus a POST_BUILD step that copies app.exe after linking.
- **12_configure_file**: configure_file: config.h is generated by CMake at configure time (not by a build step).
- **13_multiple_executables**: Three executables sharing one static library (one library node, many consumers).
- **14_interface_lib**: An INTERFACE library (no files of its own) that only adds a define and an include folder.
- **15_response_files**: Response files forced on: the link and archive steps pass their inputs through an @file (rspfile / rspfile_content in build.ninja).
- **16_spaces_in_paths**: Folder and file names containing spaces (tests the '$ ' escape in build.ninja paths).
- **17_ctest**: enable_testing + add_test: CMake adds a 'test' step to build.ninja; a test executable is built.
- **18_install_rules**: install() rules: CMake adds install, install/local, install/strip steps (and the default install path contains spaces).
- **19_precompiled_header**: Precompiled header: a separate build step compiles common.h into a .gch file before the .c files are compiled.
- **20_zlib**: Real open-source library zlib 1.3.1, unmodified source (downloaded from github.com/madler/zlib/releases, SHA-256 9a93b2b7dfdac77ceba5a558a580e74667dd6fede4585b91eefb60f03b72df23). 17 distinct C files compiled (34 compile steps) into a shared library (DLL + import library), a static library and 4 test programs; zconf.h generated by configure_file; the Windows resource file compiled by a custom command running windres.
